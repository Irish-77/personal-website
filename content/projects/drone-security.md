AIC Security is a home security system that connects different sensors and systems. As the owner leaves the house, they activate Guard mode by pressing a button — the motion sensor is then armed. When motion is detected, a drone is launched to take aerial photos, which are transmitted directly to the customer dashboard and streamed live. Using object detection, people are marked on the live stream in real time.
