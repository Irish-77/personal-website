Coin2Gether (C2G) is a social trading platform where crypto enthusiasts can share information about current trends in cryptocurrencies. It includes features such as a self-written chatbot that can carry out the user's commands on the website, and a recommender system that suggests users to follow based on social networks and similar portfolios. API statistics are also viewable via an admin dashboard.
