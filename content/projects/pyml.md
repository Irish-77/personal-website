PyML is a personal project dedicated to exploring and implementing fundamental machine learning algorithms entirely from scratch using Python and NumPy. The vision behind PyML is to provide a platform for continuous learning and hands-on experience in machine learning. As I learn new concepts and algorithms, they are coded and integrated into PyML, contributing to a growing repository of custom-built ML tools.

PyML is not intended for production use — it lacks CUDA support and isn't optimized for speed — but serves as an educational resource for those looking to deepen their understanding of machine learning algorithms and their inner workings.
